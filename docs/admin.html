Everything is connected

Products, categories, gallery images, reviews, FAQ, pages and site settings are stored as JSON files. The bundled data is also embedded in this admin page so the dashboard can load the starting data even when you open the ZIP locally. Edit them here, then publish the relevant JSON file to GitHub.

Important: GitHub Pages cannot receive and centrally store customer enquiries/reviews. Customer review forms are only local-device moderation queues until you add a backend.
Analytics: product views, shares and WhatsApp enquiries are tracked locally in this browser. True all-customer totals require a backend.

Recommended order

  1. Set categories and category images.
  2. Set products and assign one or more categories.
  3. Assign gallery images to categories.
  4. Add real customer reviews with product, name, email and phone.
  5. Update pages/homepage/SEO.
  6. Download backup and publish JSON.
